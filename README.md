# Jornada SER

App de acompanhamento entre sessões do Método SER (Mileny Matos). Site estático; os dados ficam numa API Apps Script na conta da Mileny.
- Cliente: entra pelo link pessoal `https://milenymatos.github.io/jornada-ser/?k=…`
- Terapeuta: `https://milenymatos.github.io/jornada-ser/mileny/?t=…`

Este repositório não contém dados nem chaves.
